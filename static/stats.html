📊 ReelCheck — API usage

Counters persist across restarts & deploys (stored in the DB) — they are not reset when a new version ships. Auto-refreshes every 5s.

Reading this: each row is one API key in a failover chain, tried top to bottom. Success % = successful calls ÷ attempts on that key. Quota = times it hit its free-tier limit (429). A means it's on cooldown right now.

Most free APIs don't report remaining quota; Groq does — Remaining shows its real requests-left (with reset time) fetched live from Groq's response headers. Full history is in logs/reelcheck.log.
